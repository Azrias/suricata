# Triage labels

Use these role strings as local ticket `Status:` values:

| Role / local value | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | Waiting for more information. |
| `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | Requires human implementation. |
| `wontfix` | Will not be actioned. |

These labels apply to local tasks, not upstream Redmine statuses.
